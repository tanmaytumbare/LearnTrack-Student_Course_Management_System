### JDK:
    The Java Development Kit (JDK) is a software development environment used for developing Java applications and applets. 
    It includes the Java Runtime Environment (JRE), an integrated development environment (IDE), and other tools needed for 
    Java development.

### JRE:
    The Java Runtime Environment (JRE) is a software package that provides the libraries, Java Virtual Machine (JVM), and other components 
    necessary to run applications written in Java. It does not include development tools such as compilers or debuggers.

### JVM:
    The Java Virtual Machine (JVM) is an abstract computing machine that enables a computer to run Java programs. 
    It provides a runtime environment in which Java bytecode can be executed, allowing Java applications to be platform-independent. 
    The JVM is responsible for loading, verifying, and executing Java bytecode, as well as managing memory and providing other runtime services.

### Bytecode:
    Java source code is compiled into an intermediate form called bytecode, which is a set of instructions that can be executed by the JVM. 
    Bytecode is platform-independent, meaning it can run on any system that has a compatible JVM implementation.

### “write once, run anywhere” means:
    The phrase "write once, run anywhere" (WORA) refers to the ability of Java programs to be written once and executed on any platform that has a compatible Java Virtual Machine (JVM). This is made possible because Java source code is compiled into bytecode, which is platform-independent. As long as the target system has a JVM implementation, the same bytecode can be executed without modification.

    This feature of Java allows developers to create applications that can run on various operating systems and hardware configurations without needing to rewrite or recompile the code for each specific platform. It simplifies software distribution and enhances cross-platform compatibility, making Java a popular choice for developing applications that need to run in diverse environments.
